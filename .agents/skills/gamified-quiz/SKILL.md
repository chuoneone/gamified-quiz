# 🎮 遊戲化互動測驗產生器 (Gamified Quiz Generator)

此技能專門將教師或使用者提供的任何學科試題（單選題、數學題、字詞題、問答轉選擇等），轉換為**單一獨立的遊戲式互動測驗 HTML 檔案**。
精選兩大高沉浸度遊戲模板：

1. **🎲 經典環形大富翁（Monopoly Loop）**：環形 20 格外環地圖、答對解鎖親手甩骰子、順時針步步跳躍、過起點領獎勵、世界城市地產收購。
2. **🎁 盲盒抽卡養成（Blind Box Gacha）**：答題賺金幣與特殊代幣、擬真開箱扭蛋動畫、SSR 稀有度圖鑑、動物園養成搜集。

---

## 🕹️ 遊戲模板機制介紹

### 1. 🎲 經典環形大富翁（Monopoly Loop）
- **經典 6x6 環形外環棋盤**：外環 20 個格子順時針循環繞行。
- **🚩 起點過圈機制**：每次繞完一圈經過或停在起點，自動**圈數 +1**，並發放 **+150 金幣過圈獎勵**！
- **🎲 手動甩骰（Interactive Manual Dice Roll）**：學生答對題目後，骰子亮起並提示「**請點擊骰子親自甩出步數！**」，由學生親手點擊骰子滾動擲出 1~4 步。
- **🏃 逐格跳躍動畫**：棋子沿著環形外環逐格跳躍並播放可愛跳躍音效。
- **🏙️ 世界地產與事件**：可花費金幣收購台北、東京、倫敦、紐約等世界地產（插上 `🏡 已購` 地標），並有幸運寶箱與機會命運事件。

### 2. 🎁 盲盒抽卡養成（Blind Box Gacha）
- **答題經濟與連擊**：答對獲得金幣，連續答對觸發連擊獎勵並獲得特殊代幣 🎫。
- **擬真開箱動畫**：點擊開箱時盲盒劇烈搖晃、伴隨震動音效並爆出金光與稀有度光芒（R、SR、SSR）。
- **圖鑑搜集系統**：搜集魔法動物園各式可愛夥伴，重複抽中自動升級星級與數量。

---

## 🛠️ 通用核心技術特色

- 🔊 **純程式 Web Audio 擬真音效**：答對、答錯、骰子滾動、跳躍、買地、抽卡金光、勝利號角等合成音效，完全零外掛音檔。
- 🗣️ **TTS 智慧語音朗讀**：支援題幹與選項語音朗讀，自動將分數與比例等數學符號口語化。
- 📐 **KaTeX 向量數學公式**：支援 `$math$` 語法，渲染清晰漂亮的向量數學式。
- 💾 **自動 LocalStorage 存檔**：自動記錄學生進度、金幣、資產、抽卡圖鑑與錯題歷程。
- 👨‍🏫 **教師後台（預設密碼 0000）**：隨時檢視學生答題總數、正確率、各題答題狀況與資產紀錄。
